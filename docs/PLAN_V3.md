## 1. Правила работы

Правила работы над проектом — в `CLAUDE.md` в корне репозитория. Это
единственный источник: Claude Code читает его в каждой сессии. Там же
дополнение по итогам ревью плана — компиляция `androidTest` на каждый
коммит и `@Ignore` вместо удаления устаревших проверок экранов.

### Как план согласован с этими правилами

- Коммит — одна законченная функция: несколько связанных изменений одной
  области, не больше ~300 строк боевого кода. Поэтому их 23.
- Коммиты с новым игровым правилом или экраном помечены **[ок]**: перед
  началом — короткое предложение и ожидание «ок», даже если пункт есть в плане.
- Крупные коммиты помечены **[файлы]**: перед началом — план по файлам.
- Ни один существующий тест не удаляется. Тест картинок совы переписывается
  под окрасы из `pets.json`, тест пяти периодов — под новые числа.
- Схема базы данных в v3 не меняется, поэтому тесты базы и сохранения
  остаются рабочими без правок.
- Прототипы совы и экранов — `docs/prototypes/`; числа в них совпадают
  с разделом 4.

## 2. Диагноз и цель

### Оценка на момент ревью: 5/10

Как код — 8/10: чистые слои, контент в JSON, 627 тестов. Как игра — 3/10.
Все 19 замечаний ментора сводятся к четырём корневым причинам.

| | Корневая причина | Факты | Замечания |
|---|---|---|---|
| **A** | У питомца нет потребностей | Показатели сами не падают. Нулевой план на нужное засчитывается как выполненный, питомец растёт без еды | 9, 10, 13 |
| **B** | План — отчёт, а не ограничение | Магазин списывает с общего баланса, план сверяется только вечером. В первый день 80 монет — дефицита нет | 12 |
| **C** | В заданиях нельзя ошибиться | Неверный ответ получает «Готово!» и 15 монет. У «ловушек» неверный вариант недоступен или засчитывается | 15–19 |
| **D** | Дашборд вместо игры | Главный экран — две прокрутки текста, питомец 140 dp, у совы нет эмоций, стиль ломается при росте, в магазине нет картинок | 1–3, 5, 7, 8, 11, 14 |

**Главная находка на vivo.** Ребёнок купил кашу, сова наелась, но на
нужное по плану было 30, а потрачено 14. Итог дня: «Еда осталась в
магазине», сытость −20, уход −20. Игра наказывает за экономию и учит
«потрать весь план».

2. Финансовая ценность — обучение ребёнка (приоритет).

## 3. Игровые правила v3

| № | Правило | Закрывает |
|---|---|---|
| R1 | **Ночь.** При закрытии игрового дня еда, уход и радость падают на заданные величины, но не ниже нижнего предела. Реального времени и таймеров нет | A; З13 |
| R2 | **Потребности дня.** Показатель ниже порога — потребность («хочу есть», «перья растрепались»). Считается минимальная цена её закрытия по товарам магазина, включая сочетания (две воды или каша) | A; З9, З10 |
| R3 | **Нужное выполнено = потребности закрыты.** Для обеих категорий трат план соблюдён, если потрачено не больше плана. Сэкономил на нужном — остаток переходит на завтра без наказания | A; анти-урок с vivo |
| R4 | **Лимит желаемого.** Желаемое можно купить только в пределах остатка по плану. Нужное не блокируется никогда: при нехватке денег предлагается взять из копилки | B; З12 |
| R5 | **План распределяет весь кошелёк**, а не только стартовый остаток и доход. Ползунки с шагом 1. Нераспределённый остаток — не ошибка: он переходит на завтра | B; ТЗ 2.5.5 |
| R6 | **Копилка при подтверждении плана.** Запланированная доля сразу переводится на выбранную цель | B, D; ТЗ 2.5.7 |
| R7 | **Задания доступны до плана.** Награда входит в сумму к распределению: сначала заработай, потом распредели | З5 |
| R8 | **Монеты — за верный ответ с первой попытки дня.** Повтор того же задания — тренировка без монет. Неверный ответ не тратит дневной лимит: можно заработать на другом задании. «Пройдено» — только верное | C; З15, З18, З19 |
| R9 | **Разбор ошибки.** Одно задание из `tasks.json` с условием показа «сова грустит от голода». Пока условие выполнено, разбор — задание дня. Открыл разбор — он остаётся заданием дня до вечера, даже если сову уже покормили. Разбор не показывается в общем списке заданий и не входит в счётчики «N из M» и в минимум ТЗ 2.6 | C; ТЗ 2.5.9 |
| R10 | **Рост звёздами (AD-3).** Вечером до трёх звёзд — три условия ТЗ 2.5.10: «Сыт» — потребности закрыты; «По плану» — желаемого куплено не больше плана (нужное сверх плана не нарушение); «Отложил» — копилка пополнена по плану, план копилки больше нуля. В голодный день звёзд нет совсем — прогресс не отнимается, но и не растёт. Звезда — одно очко роста. Итоги дня ставят ✓ ровно по звёздам | A; З13; Б1–Б3; ТЗ 2.5.10 |
| R11 | **Настроение совы:** грусть — если какой-то показатель ниже порога грусти; радость — если потребностей нет и радость не ниже порога потребности; иначе спокойствие | ТЗ 2.5.10 |
| R12 | **«Нужно сейчас».** В магазине товары, которые закрывают текущую потребность, помечены «нужно сейчас»; нужное, которое сове пока не требуется, — «Финни пока не нужно». Покупка такого товара не запрещена, сова мягко предупреждает | A; З: каша для сытой совы |
| R13 | **Покупка цели.** Когда копилка собрала цель, ребёнок покупает её: копилка по этой цели обнуляется, кошелёк не меняется, вещь появляется рядом с совой. Затем выбирается следующая цель | Компетенция 4; ТЗ 8.4 |
| R14 | **Перед сном.** Если потребности не закрыты, а монеты есть, окно подтверждения говорит: «Я ещё голодный. Уложить так?» | ТЗ 2.2 |

### Сова (`pets.json`)

- Рисуется кодом. Окрасы — цвета в `pets.json`: кремовый, коричневый,
  дымчатый, белый и новый рыжий.
- Аксессуары: шарф, очки.
- 5 окрасов × 2 аксессуара = 10 комбинаций даже без «без аксессуара»
  (ТЗ 2.6: не менее 9). С «без аксессуара» — 15.
- Три стадии: детёныш, подросток, взрослый — разные пропорции одной совы.
- Три эмоции: радость, спокойствие, грусть.
- Для TalkBack у совы есть описание: «Сова Финни грустит: хочет есть».

### Картинки товаров и целей

Эмодзи в контенте: поле `"icon"` в `shop.json` и `goals.json`
(🥣 каша, 💧 вода, 🪥 щётка, 💊 витамины, 🫐 ягоды, ⭐ наклейка, ⚽ мячик,
📘 книга; 📚 комиксы, 🎲 настольная игра, 🛴 самокат). Новый товар с
картинкой — правка JSON. Для TalkBack читается название, а не описание эмодзи.

## 4. Эталонный сценарий для проверки чисел

Все экраны и тесты должны сходиться с этим сценарием.

**День 1.** Сова накормлена, план соблюдён, копилка +8: три звезды (3, детёныш).

**День 2 — ошибка.**
- Кошелёк 35. План: нужное 3, желаемое 24, копилка 8.
- При подтверждении 8 уходит в копилку (копилка 16), в кошельке 27.
- Куплен мячик за 24, осталось 3. Каша за 14 не по карману: «Не хватает 11»,
  предложено взять из копилки, ребёнок отказался.
- Потребности не закрыты — звёзд нет (R10): по-прежнему 3.
- Ночь: еда 55 → 30 (нижний предел), уход 70 → 55, радость 80 → 70.

**День 3.**
- Утро: 3 + 35 = 38. Сова грустит (еда 30 < 40), «До подростка 3 из 4».
  Задание дня — разбор: верно, +10, в кошельке 48.
- Потребности: еда 30 → 70 требует +40 — дешевле всего каша и вода = 22;
  уход 55 → 70 требует +15 — витамины = 15. Итого **37**.
  После пропущенного дня еда дороже обычного (8–14).
- План: нужное 38, желаемое 2, копилка 8. Копилка 16 → 24, в кошельке 40.
- Покупки: каша 14 (еда 30 → 55, в кошельке 26), вода 8 (еда 70),
  витамины 15 (уход 75). Потрачено на нужное 37, остался 1.
- Итог: всё выполнено, +3 звезды → 6: **«Вырос! Теперь подросток»**,
  «До взрослого 6 из 10». На завтра: 1 + 2 = 3 монеты.

**Дни 4–5.** По три звезды: 9, затем 12 — **взрослый**. Копилка 32, затем 40:
в день 5 появляется «Купить комиксы», после покупки 📚 стоит рядом с совой.

**Демо-режим** (5 нажатий «Прожить день», второй день с ошибкой):
3 → 3 → 6 (подросток) → 9 → 12 (взрослый). Если ведущий в первый день
ничего не отложит: 2 → 2 → 5 → 8 → 11 — всё равно взрослый.

**Худший случай.** Еда 30 и уход 30 требуют 52 монеты при 45 доступных.
Тупика нет: за первый день закрывается еда и часть ухода, за второй —
остальное. Проверяется тестом-симуляцией; сова говорит «Сегодня всё
не успеем — начнём с еды».

## 5. Ограничения и как они соблюдаются

| Ограничение | Как обеспечено |
|---|---|
| Потребности привязаны к игровому дню | Ночь применяется при закрытии дня (`CloseDay` → `PeriodEngine`). Потребности считаются из сохранённых показателей. Реального времени нет |
| Демо-режим, 5 периодов подряд | `PlayDemoDay` закрывает потребности той же функцией, что и план. Второй день — с ошибкой. Стадии — по разделу 4 |
| Фразы и числа — в контент-паке | Числа — в `balance.json`. Фразы совы (включая 8 нынешних подсказок `main_step_*` из `strings.xml`), разбор, советы, подсказки взрослому — в `explanations.json` и `tasks.json`. Цвета — в `pets.json`, картинки товаров и целей — в `shop.json` и `goals.json`. В коде остаются только формы совы и надписи кнопок |
| Анимации отключаются настройкой | Существующая `ANIMATIONS_ENABLED` передаётся всем экранам. Выключает переходы между экранами (по умолчанию навигация делает плавную смену), полоски показателей, прыжок совы |
| Кнопки от 48 dp, текст от 16 sp | Всё нажимаемое — от 48 dp. Все стили текста — от 16 sp (сейчас местами `bodyMedium` на 14 sp), числа 20–24 sp. Проверяет тест дизайн-системы |
| Домен меняется минимально | Потребности и настроение — в существующем `PetStateEngine`. Один новый сценарий `ConfirmPlan` — по образцу `CloseDay`. Покупка цели — в существующем `SavingsEngine`. Схема базы не меняется |
| Тесты базы всегда рабочие | Компиляция `androidTest` на каждый коммит, устаревшие проверки экранов под `@Ignore` до коммита 21 (раздел 1) |

## 8. Схемы экранов

Общие правила: весь текст от 16 sp, числа 20–24 sp, всё нажимаемое от 48 dp.
Один цвет и одна иконка на категорию везде: нужное — зелёный, миска;
желаемое — оранжевый, мяч; копилка — фиолетовый, копилка. Цвет никогда
не единственный признак: рядом всегда иконка и слово. «Назад» — только
стрелка слева сверху.

### Главный

Без прокрутки на экранах от ~730 dp по высоте (vivo V2111 подходит).
На низком экране сова уменьшается до 120 dp, при крупном системном шрифте
появляется прокрутка.

```
 [🪙 48]                       [?] [🔒]
   ╭────────────────────────────────╮
   │ Доброе утро! Пришло 35 монет.  │
   │ Я голодный — начнём с завтрака?│
   ╰────────────────────────────────╯
            ( сова 170 dp )  📚
        Алекс · детёныш  ★ 3 из 4  ›
 Финни:  🥣 Еда · нужно ▓▓░  😊 ▓▓▓  ✨ Уход · нужно ▓▓░
 Монеты: 🥣 ещё 24   ⚽ ещё 2   🐷 Комиксы 24/40   ›
 🎯 Задание дня: разбор вчерашнего             +10 ›
 [ Магазин ]            [   Спланировать день   ]
```

- **Сверху:** слева кошелёк; справа две иконки по 48 dp — «Как играть»
  и «Для взрослого». В демо-режиме над ними полоса демонстрации.
- **В центре:** облачко совы; сова 170 dp, рядом вещи из купленных целей;
  «Алекс · детёныш» и строка роста «★ 3 из 4»; строка «Финни» —
  три показателя с иконкой, полосой и подписью вроде «Еда · нужно»;
  строка «Монеты» — остаток в трёх банках плана (до подтверждения —
  «Монеты ещё не разложены»).
- **Внизу:** строка задания дня; «Магазин» и главная кнопка 56 dp.
- **Крупно:** сова, число в кошельке (24 sp), главная кнопка.
- **Реагирует:**
  - кошелёк → «Кошелёк сегодня»;
  - строка роста → «Мой прогресс»;
  - строка «Монеты» → план; банка копилки → «Копилка»;
  - строка задания → задание дня;
  - «Магазин» → магазин;
  - главная кнопка по ходу дня: «Спланировать день» → «В магазин» → «Уложить спать»;
  - после покупки или задания сова меняет выражение и, если движение
    включено, подпрыгивает; облачко объясняет почему.

### Кошелёк сегодня (панель снизу)

- **Сверху:** «В кошельке 26», крупно.
- **Список:** «+3 со вчера», «+35 доход дня», «+10 разбор», «−8 в копилку»,
  «−14 каша». У каждой строки источник и сумма.
- **Реагирует:** кнопка «Понятно» закрывает панель.

### План до подтверждения

- **Сверху:** «Назад», «План на день», кошелёк.
- **В центре:** сова с облачком; три банки
  одна под другой. В каждой: название с иконкой, число (20 sp), ползунок
  с шагом 1, одна строка пояснения:
  - «Финни нужно не меньше 37: еда 22, уход 15»;
  - «Хватит на наклейку»;
  - «Если откладывать по 8 в день — комиксы через 3 дня».

  Ниже — «Осталось разложить».
- **Внизу:** «Подтвердить план» и строка «8 монет сразу уйдут в копилку».
- **Если цели нет:** в банке «Копилка» вместо ползунка кнопка «Выбрать цель».
- **Реагирует:**
  - на каждое движение ползунка сова меняет выражение и фразу: «Мне не
    хватит», «Мне столько не нужно», «А на комиксы не отложим?»,
    «Отличный план!»;
  - если монеты кончились, ползунок дальше не идёт, сова говорит
    «Сначала забери из другой банки»;
  - остаток больше нуля — не ошибка: «1 монета останется на завтра»;
  - подтверждение открывает окно «План закрепится до вечера».

### План после подтверждения

- **Три банки с полосой** «потрачено / осталось»: «Нужное: потрачено 14,
  осталось 24», «Желаемое: осталось 2», «Копилка: отложено 8».
- **Внизу:** «В магазин».

### Магазин

- **Сверху:** «Назад», кошелёк; сова с фразой о последней покупке и её цене
  («Ням, каша! Еда 30 → 55. Ещё бы водички!», «−14 монет»); фишки
  «Нужное: ещё 24» и «Желаемое: ещё 2».
- **В центре:** секции «Нужное для Финни» и «Желаемое», по 4 карточки.
  На карточке: эмодзи, название, цена (18 sp), влияние («еда +25»).
  Метки: «нужно сейчас», «Финни пока не нужно», «не в плане» (без замка,
  карточка приглушена).
- **Реагирует:**
  - карточка → окно покупки: цена, категория, влияние, «Купить» / «Не сейчас»;
    для товара «Финни пока не нужно» — строка «Я уже сыт — сохраним монеты?»;
  - «не в плане» → окно «Сегодня не в плане: на желаемое осталось 2.
    Можно запланировать на завтра» с кнопкой «Понятно»;
  - нужное при нехватке денег → окно «Не хватает N» с вариантами
    «Взять из копилки», «Выполнить задание», «Выбрать подешевле»;
  - после покупки обновляются кошелёк, фишки и облачко, сова прыгает.

### Задание (обычное и разбор)

- **Сверху:** «Назад», «Задание дня», кошелёк, тема.
- **В центре:** маленькая сова с вопросом; шаг задания — варианты ответа
  (строки 52 dp), банки или прилавок.
- **После ответа:** заголовок «Верно!» или «Не совсем» (крупно); объяснение
  совы; «+10 в кошелёк» или «Монеты — за верный ответ с первой попытки».
- **Внизу:** «Дальше» или «Попробовать ещё» (тренировка, без монет).
- **Выражение совы:** при верном ответе радость, при ошибке спокойное,
  не грустное.
- **Список заданий:** без замка до плана; у пройденного верно — отметка;
  разбор в списке не показывается.

### Итоги дня

- **Перед экраном:** окно «Закончить день?»; если потребности не закрыты,
  а монеты есть — «Я ещё голодный. Уложить так?».
- **Сверху:** «День 3 завершён».
- **В центре, сверху вниз:** облачко; сова с выражением дня; при новой
  стадии — плашка «Вырос! Теперь подросток»; три строки с ✓/✗ и пояснением
  под каждой — три звезды дня: «Сыт», «По плану», «Отложил»; «+3 звезды»
  с полосой «6 из 10»; «На завтра: 3 монеты»; один совет («Корми Финни каждый день:
  обычно еда стоит 8–14, а сегодня пришлось 22»).
- **Внизу:** «Начать день 4» — единственный нажимаемый элемент.

### Копилка

- **Сверху:** «Назад», «Копилка», кошелёк.
- **В центре:** цель с эмодзи, «24 из 40», полоса, «Если откладывать как
  обычно, по 8, — через 2 дня»; список целей; «Отложить» и «Взять из
  копилки» (с предпросмотром, как сейчас).
- **Когда цель собрана:** вместо срока — «Собрано! Купить комиксы» (56 dp),
  окно подтверждения, после покупки — «📚 теперь рядом с Финни. Выбери
  новую цель».

### Создание питомца

- **Сверху:** «Твой питомец».
- **В центре:** сова 170 dp; 5 кружков окраса по 48 dp; кнопки аксессуара
  «Без / Шарф / Очки»; поля «Твоё игровое имя» и «Имя питомца»; подсказка
  «Настоящее имя писать не нужно».
- **Внизу:** «Готово».
- **Реагирует:** выбор окраса или аксессуара сразу перерисовывает сову.

### Для взрослого

- **Сверху:** «Назад», «Для взрослого».
- **В центре, сверху вниз:** карточка «О чём поговорить сегодня» (одна из
  двух подсказок: «сова голодна» или «всё по плану»); «Чему учит игра»;
  пройденные темы только верно, без разбора (после дня 3: «Накопления
  1 из 2», остальные «пока нет»); прогресс; «Начислить 10 монет»;
  переключатели «Звук в игре» и «Движение на экране» (без изменений);
  демо-режим; удаление игры.
- **Реагирует:** начисление (раз в день), переключатели, демо-режим,
  удаление с подтверждением.

### «Мой прогресс»

Структура прежняя, весь текст от 16 sp.

## 10. Что сознательно не делаем

ТЗ этого не требует, и замечания ментора об этом не просят.

- Звуки. Переключатель «Звук в игре» остаётся как есть.
- Моргание совы, эмоция «сон», бабочка, полёт монет, конфетти, постоянное подпрыгивание.
- Второй разбор («вчера не копили») и третья подсказка взрослому — ради
  простоты логики.
- Второй шаг разбора («Что сделаем сегодня?»): объяснение уже называет
  способ исправить ошибку (ТЗ 2.5.9).
- Новые показатели для взрослого вроде «сова накормлена N дней»:
  для них нужна история, которой нет в базе.
- Серии дней с потерей прогресса, награды за ежедневный вход, случайные
  события, вторая валюта, рейтинги, уведомления — давление и тревога
  (ТЗ 8.1, 8.4, 2.7, 3.5).
- Готовые шаблоны плана («как вчера») — убирают само решение.
- Изменения схемы базы данных.
- Новые библиотеки (Rive, Lottie и т. п.).
- Обязательный плейтест с детьми. Желателен, только с согласия родителей.
  Для ТЗ 8.4 достаточно экспертной проверки: 19 замечаний ментора
  и таблица «замечание → что исправлено».

## 11. Известные ограничения

Указываются в README и в документе по разделу 5.

- Главный экран помещается без прокрутки на экранах от ~730 dp по высоте;
  на 360 × 640 dp появляется прокрутка. ТЗ задаёт только ширину 360 dp.
- Контент заданий фиксированный: ответ можно узнать, ошибившись, и получить
  монеты за это задание в другой день. Награда небольшая (10), обучение
  при этом всё равно происходит.
- После долгого пренебрежения потребности дороже дневного бюджета;
  восстановление занимает два дня.
- После стадии «взрослый» рост заканчивается; мотивацией остаются цели
  и коллекция вещей.

## 14. История плана

**Первый вариант — 6 этапов, «довести до 10».** Слишком много новых систем:
жёсткие конверты, звёзды опыта, события, комната питомца, звуки.
Для ребёнка сложнее, и это почти переписывание приложения.

**v2 — «не менять всё».** Упор на исправление правил, которые учат
неправильному, и на упрощение экранов. Ревью на макете нашло: мелкий текст,
грустная сова при ошибке в задании, перебор ответов ради монет, лазейка
«всё в нужное», противоречия в числах между экранами.

**v3.** Асимметричные банки (лимит только на желаемое), потребности
списком, монеты только за первую попытку, разбор своей ошибки, подсказка
взрослому. Ревью нашло: ежедневная грусть, замки в магазине, лишние кнопки
± рядом с ползунками, скрытое меню.

**v3.1.** Утро без грусти, влияние товаров на карточках, живой срок
до цели, магазин без замков, сова рисуется кодом.

**Финальная сверка с ТЗ.** Добавлены видимые начисления (2.5.4),
исправленный текст про доход, отключение переходов (3.6), текст от 16 sp
везде, срок до цели как условие (2.5.7), «пройдено только верное» (2.5.11),
настоящая нехватка денег в демо, экспертная проверка (8.4), план по всему
кошельку. Убраны звуки и декоративные анимации.

**Правила работы.** 31 → 39 коммитов по правилу «одно изменение, до ~300
строк»; коммит с архитектурными решениями и коммит обновления тестов
экранов; существующие тесты не удаляются; переключатель звука остаётся.

**Ревью финального плана — 10 исправлений.**
1. Сова росла без еды (+4 очка в день) → в голодный день очков нет,
   пороги 0/8/20. Сова вырастает на 3-й день, сразу после исправленной
   ошибки.
2. Тесты экранов, переставшие компилироваться, остановили бы тесты базы →
   компиляция `androidTest` на каждый коммит и `@Ignore` вместо удаления.
3. Ползунок с шагом 2 не раскладывал нечётную сумму → шаг 1, остаток —
   не ошибка.
4. Разбор попадал в общий список и счётчики → скрыт из списка, счётчиков
   и минимума ТЗ 2.6.
5. Разбор пропадал, если сначала покормить сову → открытый разбор остаётся
   заданием дня.
6. У совы не было описания для TalkBack → добавлено.
7. Худший случай «потребности дороже бюджета» → проверяется симуляцией,
   у совы есть фраза.
8. Два времени в правиле «первая попытка» → проверить, что они от одних
   часов.
9. Ответы можно выучить, ошибившись → известное ограничение в документации.
10. «Без прокрутки» только от ~730 dp по высоте → известное ограничение.

Упрощения: один разбор вместо двух, две подсказки взрослому вместо трёх.

**Улучшения логики и интерфейса.** Покупка цели и коллекция вещей рядом
с совой; «Хочу завтра»; «нужно сейчас» в магазине; предупреждение перед
сном; строки «Финни» и «Монеты» на главном вместо трёх плиток; эмодзи
товаров и целей в контенте; одна кнопка «Назад»; округлый шрифт по желанию.
39 → 45 коммитов, ~+450 строк боевого кода.

**Укрупнение до 20 оставшихся коммитов.** Правило ослаблено: один коммит —
одна законченная функция (несколько связанных изменений одной области),
лимит ~300 строк остаётся. Убраны «Хочу завтра» и шрифт. 45 → 23 коммита
(1–3 уже сделаны), ~3 580 строк боевого кода.

**v4 — логика (25.09).** Ревью после коммита 20: итоги ставили ✓✓✓ сами,
план нельзя было нарушить, желаемое не давало ничего, дни одинаковые. Рост
теперь — три звезды ровно по ТЗ 2.5.10, план мягкий, у дней появляется
сюжет. 10 коммитов — этап 6 раздела 7.
