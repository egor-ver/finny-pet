# Прототипы v3

Эталон для реализации плана из `docs/PLAN_V3.md`. Не входят в приложение.

| Файл | Что это |
|---|---|
| `owl.js` | Сова, нарисованная кодом: 5 окрасов, 3 стадии, 3 эмоции, шарф и очки. Эталон геометрии для `Owl.kt` (коммит 17) и цветов для `pets.json` (коммит 15) |
| `owl.html` | Просмотр совы: переключатели и все комбинации внешности |
| `owl.png` | Снимок `owl.html` |
| `screens.html` | 9 экранов на эталонном сценарии (раздел 4 плана): разбор, главный, кошелёк, план, магазин, итоги дня, покупка цели, создание питомца, раздел для взрослого. Ползунки плана и выбор внешности работают |
| `screens.png` | Снимок `screens.html` |

## Как открыть

`owl.html` и `screens.html` подключают `owl.js` из той же папки. Открываются
двойным щелчком в Chrome или Edge. Если браузер не загрузил скрипт и совы
не видно, запустить из этой папки:

```
python -m http.server 8765
```

и открыть `http://127.0.0.1:8765/screens.html`.

## Как переносить в Compose

- Поле рисования — 240 × 262; в `Canvas` координаты масштабируются
  под размер компонента.
- Кривые из `owl.js` (`M`, `C`, `Q`, `A`) переносятся в `Path`
  один к одному: `moveTo`, `cubicTo`, `quadraticTo`, `arcTo`.
- Цвета окрасов — в `pets.json`, геометрия стадий — в коде.
- Картинки товаров и целей в прототипе — те же эмодзи, что пойдут в
  `shop.json` и `goals.json`.
- В приложении весь текст от 16 sp и всё нажимаемое от 48 dp;
  прототип нарисован в этих пропорциях.
